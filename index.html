Architecture Decision Record

Hosting Platform Selection & Justification

Task 2 provided multiple hosting options: AWS S3, Netlify, or GitHub Pages. Here is the engineering rationale for choosing GitHub Pages and declaring the others unwanted.

Evaluation Parameter GitHub Pages (CHOSEN PLATFORM) AWS S3 (DECLARED UNWANTED) Netlify (DECLARED UNWANTED)
Selection Status ✔ SELECTED AS SOLE HOST ✖ Unwanted / Excluded ✖ Unwanted / Excluded
GitOps / CI/CD Integration Native via GitHub Actions (Zero third-party tokens) Requires AWS IAM keys & S3 sync scripts Requires third-party webhook connection
Operational Cost $0.00 / Free (No credit card / billing risk) Pay-per-request / egress bandwidth risk Free tier limits (100GB monthly cap)
Edge CDN & SSL Automated Anycast CDN + Auto Let's Encrypt TLS 1.3 Requires separate CloudFront + ACM configuration Netlify Edge CDN
Engineering Rationale Eliminates configuration overhead, guarantees 100% uptime, and delivers a deterministic deployment URL without credential exposure. Unwanted for this project because it introduces unnecessary IAM credential management and potential cloud billing for a static payload. Unwanted because it adds a redundant third-party intermediary when GitHub already provides direct edge hosting.
